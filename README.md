## 📌 О проекте

Проект представляет собой **высоконагруженный клиентский интерфейс** для частной компании. Реализована двухролевая модель:

- **Публичная часть** — визитка компании с актуальными новостями, контактами и картой.
- **Админская панель (Admin)** — защищенный интерфейс для модерации и публикации постов и статей.

## 🚀 Стек технологий

| Категория | Технологии |
| :--- | :--- |
| **Ядро** | [Next.js](https://nextjs.org/) (App Router), [TypeScript](https://www.typescriptlang.org/) |
| **Управление состоянием** | [Redux Toolkit (RTK)](https://redux-toolkit.js.org/) + RTK Query |
| **Стилизация** | [Tailwind CSS](https://tailwindcss.com/) (утилиты) + SCSS Modules |
| **UI Библиотека** | [Ant Design](https://ant.design/) |

| **Линтинг/Формат** | ESLint |

## 🏗 Архитектурные решения

### ⚡️ Серверный рендеринг (SSR/SSG)
- Используется для **SEO-оптимизации** главной страницы и карточек постов.

### 🔄 Интеграция API
- **Backend:** Взаимодействие с серверной частью на **NestJS** через REST API.
- **Frontend:** RTK Query выступает единым источником данных, автоматически инвалидируя кэш после изменений в админке.

### 📱 Адаптив
- **Mobile-First** подход с использованием Tailwind, обеспечивающий корректное отображение на всех устройствах.
